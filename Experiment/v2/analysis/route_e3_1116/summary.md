# E3 사용자 지정 동선 (2026-11-16)

LLM 추가 호출 없음. gemma4:e4b ZS 응답 240개 × seed 100~109. 조건당 2,400장.
- ZS_PT: 무작위 경로 선확보(path_required=true 고정, E1과 동일)
- ZS_R1/R2/R3: 연구자가 정한 동선을 FixedCorridor로 고정 (route_R*.txt, '#'=동선 칸)
  - R1 직선형 57칸(다리 경유), R2 서쪽·북쪽 가장자리 우회 91칸, R3 동쪽 가장자리 우회 89칸. 세 동선 모두 ValidateCorridor 통과

- 지름길 = 생성된 맵의 BFS 최단 경로가 지정 동선보다 짧은 경우. 즉 동선 고정은 "그 길이 반드시 열려 있음"을 보장하지만, "그 길로만 다니게 함"은 보장하지 않음
- 통계(목표 맵별 평균, ZS_PT 대비 쌍체 Wilcoxon, 3동선 × 3지표 9개 Holm): R1 block_mae +0.0045 (p_holm 0.014), R3 type_l1 −0.0108 (p_holm 0.0006, 오차 감소). 나머지 7개는 보정 후 유의차 없음. 상세 stats_e3.csv
- 해석 주의: 목표 맵은 무작위 경로로 생성됨 → region_mae 차이는 E2와 같은 이유로 조심해서 해석. 동선은 실제 인테리어 도면이 아닌 연구자 예제
