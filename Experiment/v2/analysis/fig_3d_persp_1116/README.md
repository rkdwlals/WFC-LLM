# E4 논문용 3D 그림 — 원근 판 (2026-11-16, L11)

fig_3d_1116/(정사영 52°, 데모와 같은 시점)과 같은 맵·같은 수치를 원근 카메라로 다시 그린 판이다. 데모 카메라는 바꾸지 않았다.
- 카메라: 원근(시야각 30°), 맵 중앙 남쪽 위에서 40° 내려다봄
- 그림자: 방향광 1개(남서쪽 위), PCF soft shadow
- 모양·크기·색: DemoApp.cs(v9)와 동일. 바닥 타일은 이음새를 줄이려고 1.002배
- 8개 패널을 같은 영역으로 잘라 크기를 맞춤 (원본 1400×1150 → 1145×684)
- 입력 격자, 예시 선정 규칙, 수치는 fig_3d_1116/README.md와 같음. 렌더러가 계산한 최단 경로 길이(57·91·87)도 같음
