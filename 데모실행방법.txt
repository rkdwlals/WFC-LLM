LLM 기반 WFC 제약 생성을 통한 프롬프트 기반 장애물 배치 데모 파일 사용법

순천향대학교 메타버스&게임학과 20233618 강지민

[실행 환경]
  - Windows 10/11 (64비트)

[설치(처음 한 번만 하시면 됩니다.)]
  1) https://ollama.com/download 에서 Ollama(Windows)를 내려받아 설치합니다.
  2) 명령 프롬프트(cmd)를 열고 아래 명령을 입력해 모델을 받습니다.
       ollama pull gemma4:e4b
  3) 받기가 끝나면 cmd 창은 닫아도 됩니다. Ollama는 백그라운드에서 자동으로 실행됩니다.

[실행]
  1) 압축을 푼 폴더에서 LLM_WFC_Demo.exe 를 실행합니다.
  2) 화면 왼쪽 아래에 "LLM 연결됨 (gemma4:e4b)"이 표시되면 사용할 수 있습니다.
     "LLM 연결 안 됨"이 표시되면 Ollama가 실행 중인지 확인한 뒤 [다시 확인]을 누릅니다.

[종료]
  - 왼쪽 아래 [종료] 또는 Alt+F4
